# E-comerce Sales Analysis - PostgreSQL

End-to-end SQL analysis of a Kenyan e-comerce dataset covering 300 customers, 300orders, 100 products across 10 categories and 5 cities. Built as a portfolio project demonstrating proffesional SQL skills from basic aggregations to advanced RFM segmentation and cohort analysis.

---

## Key Business Insights

- **Mombasa dominates revenue** - highest AOV at KHS 18,926 per order, 7x higher than Nakuru (KSH 2,679) despite annual order volumes
- **Furniture + Electronics = 75.6% of all revenue**
